# Refuge theme for Discord

A customized version of the [Dark+ Theme](https://github.com/DevEvil99/DarkPlus-Discord-Theme) by [DevEvil99](https://github.com/DevEvil99).

Features:
- More compact message layout with tweaked rounding of the message background. The theme respects your spacing settings in `Settings › Experience › Accessibility`.
- Rounded square avatar icons, unless the user has a Nitro avatar decoration.
- Reworked highlight when hovering over messages, with improved animations.
- The same purple color scheme from Dark+, with added yellow accents.

## Setup

Requires some way of installing themes on Discord, such as [Vencord](https://vencord.dev).
For Vencord, navigate to `Settings › Vencord Settings › Themes`, copy `refuge.theme.css` into the themes folder and enable it from the settings.
